    Particles, HUD and geometry

    The layers that work with any backend: particles and sound, a HUD anchored to the world, and geometry through the official API.

    7. Level 0 · Particles and sound

    Shapes and velocities

    ctx.particles().emit(particle, shape, count, velocity) spreads particles over a shape and gives them an initial velocity. Everything is deterministic with the tick's seed.

    Shape For
    point(p) A point with random directions
    ring(c, radius, phase), ring(c, normal, radius, phase) Regular rings; animate phase to spin them
    disc(c, normal, radius) Disc with uniform density
    sphere(c, radius), dome(c, radius) Sphere or dome surface (Fibonacci spiral)
    ball(c, radius) Sphere volume
    helix(base, axis, radius, height, turns, phase) Auras, tornadoes, columns
    line(a, b) Trails, beams, connections
    arc(c, yaw, radius, from, to) Weapon swings in front of the viewer
    cone(apex, direction, angle) Jets, sprays, muzzle flashes
    box(aabb) Dust or ambience in an area
    spiral(c, normal, r0, r1, turns, phase) Whirlpools, portals
    .jitter(d), .onGround(level, lift) Position noise, snap to the terrain
    Velocity For
    NONE, fixed(v) Still or in one direction
    along(v), along(min, max) Outwards from the shape (bursts); negative = inwards
    random(v) Random
    towards(target, ticks) Converge and arrive on time (energy charge-ups)
    awayFrom(c, v), swirl(c, axis, v) Explosion from a point, swirl
    .plus(other), .scale(k) Combine

    ctx.particles().lod(n, pos, fullDistance) reduces the count with distance and applies the density chosen by the player.

    The configurable blocmpact:fx particle

    One particle covers sparks, embers, smoke, motes or snow: all of its properties are data.

    FxParticleOptions smoke = FxParticles.options()
    .colors(0xC0303030, 0x00101010).size(0.3f, 1.2f).lifetime(60).jitter(0.4f)
    .gravity(-0.002f).drag(0.94f).spin(0.02f).sprite(FxParticles.PUFF).fadeIn(0.15f)
    .blend(FxParticleOptions.Blend.TRANSLUCENT).emissive(false).build();
    Property What it does
    color, colorEnd ARGB at birth and at death. With only color, it fades to transparent
    size(start, end) Half size of the quad in blocks (vanilla ones are around 0.1)
    lifetime, jitter Life in ticks and random variation of life and size (0–1)
    gravity, drag Blocks/tick² downwards (negative rises) and velocity kept per tick
    spin Rotation in radians per tick
    blend TRANSLUCENT, ADDITIVE (glow) or OPAQUE
    emissive, collide Ignores world light; collides with blocks
    facing CAMERA or VERTICAL (only turns around the vertical axis)
    sprite INDEX (with sprite(i)), RANDOM or ANIMATE (steps through the set over its life)
    curve, fadeIn Color and size curve; fraction of life spent appearing

    blocmpact:fx sprites: SOFT 0, DOT 1, RING 2, SQUARE 3, STREAK 4, CROSS 5, PUFF 6, THIN_RING 7. They are neutral white shapes meant to be tinted. To use your own textures, register your own type with the same behavior: FxParticles.register(id) in your ModInitializer and assets/<ns>/particles/<path>.json with {"textures": ["ns:a", "ns:b"]}. Blocmpact registers the client provider for you.

    Sound

    ctx.sounds().at(event, pos, volume, pitch);          // positional; range = 16 × volume
ctx.sounds().head(event, volume, pitch);             // the same everywhere (warnings, hits that must be felt)
ctx.sounds().edge(event, center, radius, v, p);      // large areas: plays at the nearest edge, or on you if you are inside
ctx.sounds().atSpeedOfSound(event, pos, v, p);       // travels at 17 blocks/tick: flash now, boom later
ctx.sounds().later(ticks, () -> ...);                // anything delayed by real ticks

    Sounds use the MASTER category by default (category(...) changes it). If silencing(frame) returns true, the world goes quiet except MASTER, PLAYERS and UI: silence before the hit weighs more than any particle.

    8. Level 1 · HUD

    @Override public void hud(HudContext h) {
    float t = time(h.partial());
    try (Canvas c = h.canvas(720)) {                     // a 720-tall canvas at any GUI scale
        c.spaced("TITLE", c.width() / 2, 60, 3f, FxMath.lerp(4, 1, FxMath.smooth(t / 10f)), 0xFFFFFFFF);
        Vector3f p = c.project(origin(h.partial()));     // world point → canvas (z ≤ 0 = behind)
        Vector3f q = c.clampToEdge(p, 24);               // off screen: pinned to the edge with an angle
        if (Float.isNaN(q.z)) c.reticle(q.x, q.y, FxMath.lerp(60, 12, FxMath.smooth(t / 8f)), 8, 2, 0xFFFF4040);
        else c.arrow(q.x, q.y, q.z, 12, 2, 0xFFFF4040);
    }
}

    Canvas offers rect, gradient, outline, line, corners, reticle, bar, arrow, image/imageCentered (FxTextures gives you circles, rings and halos), text, textCentered, textRight, spaced, glow (a halo made of 8 offset copies), outlined, textWidth, project and clampToEdge. Every coordinate accepts decimals, so animations are smooth.

    On a 720-tall canvas, use a text scale of 1.3 or more for telemetry and 1.8 for warnings: at 1.0 it cannot be read in small windows.

    9. Level 2 · Geometry

    @Override public void geometry(GeometryContext g) {
    float p = g.frame().partial();
    Vec3 o = origin(p);
    g.draw(FxRenderTypes.additive(FxTextures.SOFT), m -> m.billboard(o.add(0, 2, 0), 1.5f, 0f, 0xFF80C0FF));
    g.draw(FxRenderTypes.additive(), m -> m.ring(o.add(0, 0.05, 0), new Vec3(0, 1, 0), 3f, 3.4f, 64, 0xFFFFFFFF, 0x00FFFFFF));
}
    Mesh Shape
    quad, quadFacing Four points; quad always faces the camera, quadFacing faces a given direction
    billboard Camera-facing square or rectangle, with rotation and UVs
    beam A segment as a camera-facing strip (lasers, tracers)
    ribbon(points, widths, colors) A strip through many points (trails, lightning)
    ring, disc Ring or disc in any plane, with inner and outer color
    cylinder, sphere, box Tubes, columns, bubbles, boxes (faces pointing out)
    doubleSided(true) Also see the inside of closed shapes
    light(block, sky) World lighting (full bright by default)
    FxRenderTypes Blending
    additive() Vertex color added to the scene, no texture
    additive(texture) Texture × color, added (halos, glints, glyphs)
    translucent(texture) Texture with normal alpha, full bright (smoke, decals, panels)
    beam(texture, translucent), swirl(texture, u, v) Beacon-style beam, and a texture with animated scrolling

    These types go through the official 26.3 API: they respect world depth, fog and improved transparency, and they work with Vulkan. For anything more advanced you have g.collector() and g.poseStack().
