    Screen passes

    Full-screen shaders over the image: template, uniforms, targets, GLSL library, compositor and impact frames. OpenGL only.

    10. Level 3 · Full-screen passes

    How it works

    Once the world has been drawn (before the hand and the GUI), Blocmpact copies the image, runs every effect's passes in a chain at a resolution that adapts to GPU time, generates the bloom of the light the effects added, and applies the compositor. An effect does not draw: it describes passes.

    private static final Identifier WAVE = Identifier.fromNamespaceAndPath("mymod", "wave");

@Override public void passes(Frame f, PassCollector out) {
    float since = Math.max(0, since(20, f.partial()));
    out.add(WAVE, u -> {
        u.world("Target", origin(f.partial()));               // camera-relative position
        u.f4("P0", 3f, since, seedF(), 1f);                   // free meaning: you decide
        u.color("P1", params().getColor("color", 0xFFFFFFFF));
    });
}

    The program mymod:wave is assets/mymod/fx/wave.fsh. Blocmpact prepends #version 150 and blocmpact:lib/core.glsl, expands #include (each file once) and adds #line so errors report file and line.

    Shader template

    // assets/mymod/fx/wave.fsh — P0 = (radius, seconds, seed, intensity), P1.rgb = color
#include "blocmpact:lib/light.glsl"

void main() {
    beginPixel(texCoord);
    vec3 rd = viewDir(texCoord);                         // view ray (the camera is at the origin)
    float d = sceneDepth(texCoord);
    bool sky = skyAt(d);
    vec3 scene = sky ? rd * 1e5 : unproject(texCoord, d);   // pixel position, camera-relative
    float sceneT = length(scene);                        // anything with t > sceneT is hidden
    vec3 base = texture(DiffuseSampler, texCoord).rgb;   // the scene (or the previous pass)
    vec3 glow = vec3(0.0);                               // added light

    glow += P1.rgb * beamGlow(rd, sceneT, Target, Target + vec3(0.0, 40.0, 0.0), P0.x * 0.2) * P0.w;
    if (!sky) {
        vec3 rel = scene - Target;
        glow += P1.rgb * frontRing(length(rel.xz), P0.y * 12.0, 1.2) * P0.w;
        base = base + base * P1.rgb * lightReach(length(rel), P0.x * 2.0) * 0.6 * P0.w;   // the light tints what it touches
    }
    fragColor = vec4(tonemap(base + glow), 1.0);         // alpha 1 = real scene (bloom uses it)
}

    Rules that work:

    • Keep base and glow apart: base is the modified scene (darkened, tinted); glow, the added light. Finish with a tonemap.
    • Energy around 1 keeps the color; above that it drifts to white.
    • Darken to light up: lowering the scene makes the light stand out without burning it.
    • Hide what is behind the terrain by comparing with sceneT.
    • Never thinner than a pixel: use fxPixel and fxAA (the light.glsl functions already do).
    • Order inside a pass: first whatever moves the UV, then read the scene, last whatever changes the color.

    What each pass receives

    Uniform Content
    DiffuseSampler Output of the previous pass (the scene for the first one)
    DepthSampler Minecraft's depth (reversed Z in 26.3: skyAt takes care of it)
    SceneSampler The untouched scene
    InvProj, InvView, ViewProj, Proj, View Matrices (the view is rotation only)
    OutSize, ScreenSize Pixels of the target and of the screen
    DepthZeroToOne, ReverseZ, GameTime Depth conventions and wall-clock seconds (back to 0 every hour)
    CameraPos Camera modulo 8192: for world-anchored noise (fbm3(scene + CameraPos))
    P0…P7, Pts[32], Target Free for your effect

    From Java (Uniforms): f1…f4, i1, vec4s (lists such as Pts), mat4, v3, world (position → camera-relative), screenPoint (position → screen uv), color, rgb, texture(name, id[, linear, repeat]) for your mod's PNGs, target(name, targetName) and history(name, secondsAgo). Uniforms the shader does not declare are ignored.

    Advanced PostPass features

    out.add(PostPass.of(MASK, u -> {...}).to("mymod_mask"));                    // writes a named target (not the chain)
out.add(PostPass.of(USE, u -> u.target("Mask", "mymod_mask")));             // another pass reads it
out.add(PostPass.of(TRAIL, u -> u.target("Prev", "mymod_trail")).toPersistent("mymod_trail"));   // feedback between frames
out.add(PostPass.of(ECHO, u -> u.history("Past", 0.5f)));                   // the image from half a second ago
out.add(PostPass.of(BLUR, u -> {...}).to("mymod_blur").scale(0.5f));        // half-resolution target
out.add(PostPass.of(PATTERN, u -> {...}).overlay());                        // after the compositor, no bloom or grading
out.add(PostPass.of(PROG, u -> {...}).define("QUALITY", 2));                // #define QUALITY 2 (one compile per variant)

    Named targets are RGBA16F (lowPrecision() makes them RGBA8) and are shared between effects: put your mod id or the instance id in the name. Persistent targets are double-buffered: you read the previous frame and write the new one.

    GLSL library

    Include only what you use: #include "blocmpact:lib/<module>.glsl".

    Module Content
    core.glsl (always) saturate, lum, remap, window, rot2, centered, hashes hash11/12/22/13/33, skyAt, unproject, viewDir, sceneDepth, scenePosAt, sceneDistAt, sceneNormalAt, project, beginPixel (fxPixel, fxAA), raySphere, rayCylinderY, rayPlane, rayBox, rayPointDist, raySegmentDist, sdSegment2, profiles softGlow, gauss, stroke, ring, tonemap
    noise.glsl vnoise2/3, gnoise2/3, fbm2/3 (with octaves), ridged2, turbulence2, voronoi2/3, cellEdges, warp2, curl2
    sdf.glsl 2D: sdCircle, sdBox2, sdRoundBox2, sdRing2, sdArc2, sdPolygon, sdStar, sdPolygram ({n/k}), sdCross2, sdTriangle2, repeatPolar, repeatGrid. 3D: sdSphere, sdBox, sdRoundBox, sdCapsule, sdTorus, sdCylinderY, sdConeY, sdPlane, smin, smax, opOnion… Raymarching with #define FX_SCENE(p): fxMarch, fxNormal
    color.glsl toLinear, toGamma, rgb2hsv, hsv2rgb, Oklab (mixOklab), hueShift, saturation, contrast, posterize, blackbody, wavelength, hueWheel, cosinePalette, gradient4, blend modes (blendScreen, blendOverlay, blendSoftLight…), illuminate, tonemaps Reinhard, Exp, ACES and its inverse
    light.glsl In the world: beamGlow, lightningGlow, columnHit, sphereShell + fresnel, decalUV + decalAA, planeUV, frontRing, frontRefract, lightReach, occluded, pointGlow, pointSpikes
    screen.glsl Distortions (wobble, heatHaze, swirl, pixelate, barrel, pinch, ripple, kaleido, mirrorX), filters (chromatic, radialBlur, directionalBlur, boxBlur, glitch, lightShafts), masks (vignetteMask, scanlines, depthEdges, colorEdges, distanceFront, bayer4)
    shapes.glsl Crisp symbols: dashedRing, ticks, radarSweep, hexGrid, glyph (endless alphabet from a seed), glyphBand, revealAround, 7-segment digits (sdDigit, readout), isoLine, starField
    volume.glsl Participating media with #define FX_DENSITY(p) (and optional FX_LIGHT(p, d)): marchVolume with Beer-Lambert and a random per-pixel start

    The functions return intensities, distances or geometric data: the color and how to combine them are up to you.

    The compositor (ScreenFx)

    Every effect in range writes into the same ScreenFx each frame, and a single full-resolution pass applies it. Everything starts neutral.

    Method Combination Typical use
    shake(a) maximum Image shake: 0.15 hit, 1 impact
    aberration(a) maximum Tension, an overdriven lens
    zoomBlur(a, u, v), zoom(scale, u, v) strongest Suction, push, punch-in
    bloom(strength, radius) maximum Halo of the added light (not of the whole image)
    thresholdBloom(a), adaptation(a) maximum Invented images (classic threshold); auto exposure
    exposure(k), tint(r,g,b) multiply Global brightness and tint
    lift(r,g,b), hueShift(turns) add Tinted shadows, hue rotation
    saturation(s), contrast(c, pivot), gamma(g) farthest from 1 Grading
    grayTint(r,g,b), keepColor(a, threshold) last / maximum A gray world where only light keeps its color
    vignette(a, r,g,b), vignetteShape(in, out) strongest Frame the eye
    flash(a, r,g,b) strongest Flash (above 1 it burns to white)
    fade(a, r,g,b) strongest Fade to a color
    grain(a) maximum Grain
    holdFps(fps) lowest Held frames ("animating on twos" at 12)
    frozenWorld(k, r,g,b) shortcut Desaturation + keep color + contrast + grain
    impact(style, t, u, v), impactCycle(...) last Impact frames

    Impact frames

    ImpactFrame ink = ImpactFrame.builder(ImpactFrame.Mode.TWO_TONE).paper(0xFFF2E8D5).ink(0xFF1A0F0A).build();
ImpactFrame halftone = ImpactFrame.builder(ImpactFrame.Mode.HALFTONE).cell(7).build();
s.impactCycle(since(IMPACT, f.partial()), 1 / 12f, focus.x, focus.y, ink, halftone, ink.toBuilder().invert(true).build());

    Modes: TWO_TONE (two local tones + ink + core), SILHOUETTE, LINE_ART, HALFTONE, POSTERIZE (cell = levels), NEGATIVE, GLITCH, RAINBOW (hue wheel around the focus), INK_OUTLINE (outlines over the real image). Colors, bias (bias), outline strength (edges), cell, glitch, spin and inversion are yours. Rotate the sequence when the hit repeats.
