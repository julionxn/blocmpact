    Data-driven effects

    Complete effects in JSON inside a resource pack, with expressions in any number and reloading with F3+T.

    12. Data-driven effects

    A file assets/<ns>/blocmpact/effects/<path>.json defines the type <ns>:<path>. If a Java effect has the same id, the Java one wins. F3+T reloads everything and errors reach the chat with their path (mymod:x.timeline[2].do[0].particles).

    The same format works outside resource packs (generated in code, read from a config file, received over the network) with ClientEffects.fromJson(id, json), which validates it right away and throws IllegalArgumentException with the JSON path of the error. F3+T does not reload that definition, but it does reload the shaders and textures it names:

    // like any other type
ClientEffects.register(id, ClientEffects.fromJson(id, json));
// once, without registering
ClientEffects.play(EffectSpawn.local(id, pos, params), ClientEffects.fromJson(id, json));

    Any number can be an expression (section 14). Positions are "origin", "camera", [dx, dy, dz] (offset from the origin), {"abs": [x, y, z]}, {"param": "name"} or {"offset": [...], "from": ...}. Colors are "#RRGGBB", "#AARRGGBB", the name of a color parameter, [r, g, b(, a)] with 0–1 expressions, or a number.

    13. JSON format reference

    Root

    Key Content
    duration Timeline ticks (expression evaluated at start; -1 or absent = until stopped)
    range Radius within which it is drawn (512)
    defaults Default parameters (launch parameters override them)
    vars Derived variables, in order; recomputed on every evaluation
    state Variables that persist between ticks (initial values); changed with the set action
    silence Condition that silences the world
    stop {"outro": ticks, "do": [actions]}: what to do when asked to stop
    timeline List of entries that run actions
    events {"name": [actions]}; the event data arrives as event_<key>
    passes, screen, environment, camera, entity, hud, geometry The layers (below)
    hud_height Height of the HUD canvas (720)

    Timeline

    { "at": 20, "do": [ ... ] }                              // at tick 20
{ "from": 0, "to": 40, "every": 2, "do": [ ... ] }      // every 2 ticks between 0 and 40
{ "when": "t > 60 && rand(tick) < 0.3", "do": [ ... ] }  // whenever it holds

    Actions (all accept "when"):

    Action Fields
    particles particle (id or object with options; "$param" is replaced by the parameter), shape, count, velocity, lod (full-detail distance), at
    sound id, volume, pitch, mode (at, head, edge, speed_of_sound), at, radius
    spawn type, at, params (expressions or "#color"), inherit_params
    set {"variable": expression} on state
    finish true: ends the effect

    shape: type and its fields, plus jitter and ground (height above the terrain) for any of them:

    type Fields
    point —
    ring, disc radius, phase (ring only), normal
    sphere, dome, ball radius
    helix radius, height, turns, phase, axis
    line to (position)
    arc yaw, radius, from and to (degrees)
    cone direction, angle
    box size ([x, y, z])
    spiral inner, radius, turns, phase, normal

    velocity: type (none, along with speed and max, fixed with vector, random, towards with target and ticks, away, swirl with axis) and plus (another velocity added to it).

    Configurable particle in JSON: {"type": "blocmpact:fx", "color", "color_end", "size", "size_end", "lifetime", "jitter", "gravity", "drag", "spin", "blend": "translucent|additive|opaque", "emissive", "collide", "facing": "camera|vertical", "sprite": "index|random|animate", "sprite_index", "curve": "linear|ease_in|ease_out|smooth", "fade_in"}.

    Passes

    "passes": [ {
  "program": "mymod:wave", "when": "t > 20", "stage": "scene", "output": null, "persistent": false,
  "scale": 1, "hdr": true, "defines": { "QUALITY": 2 },
  "uniforms": {
    "Target": { "world": "origin" },
    "P0": ["radius", "max(0, (t - 20) / 20)", "seed", "k"],
    "P1": { "color": "color" },
    "Focus": { "screen": [0, 2, 0] },
    "Noise": { "texture": "mymod:textures/fx/noise.png", "linear": true, "repeat": true },
    "Mask": { "target": "mymod_mask" },
    "Past": { "history": 0.5 },
    "Pts": { "points": [ { "at": [0, 0, 0], "w": "t" }, { "at": [5, 0, 0] } ] },
    "Brightness": "0.5 + 0.5 * sin(t)"
  }
} ]

    Screen

    Scalars (number, expression or {"value", "when"} object): shake, aberration, threshold_bloom, adaptation, exposure, saturation, gamma, hue_shift, grain, hold_fps. Objects: contrast {value, pivot}, bloom {strength, radius}, keep_color {amount, threshold}, vignette {amount, color, inner, outer}, flash {amount, color}, fade {amount, color}, zoom_blur {amount, at}, zoom {scale, at}, impact {mode, paper, ink, highlight, bias, edges, cell, glitch, spin, invert, time, at, when}, impact_cycle {start, duration, at, frames: [ {mode, ...} ]}. Plain colors: tint, lift, gray_tint.

    Environment

    All accept weight and when. With color: fog_color, sky_color, cloud_color, sunrise_color, sky_light_color, ambient_light, block_light_tint, night_vision_color, water_fog_color, fog_final_color. With start and end: fog_distance, fog, water_fog_distance. With value: sky_fog_end, cloud_fog_end, fog_sky_end, fog_cloud_end, sun_angle, moon_angle, star_angle, star_brightness, cloud_height, sky_light_factor, rain, thunder. Plus cloud_hole {radius, ragged, at}.

    Camera and entity

    camera: shake, shake_frequency, roll, yaw, pitch, fov_scale, fov (expressions) and offset ([x, y, z]). entity (applies to the anchor entity): outline (color), when, poses {"part": {x_rot, y_rot, z_rot, weight, mode: "add|set", visible}}.

    HUD

    Elements with type, when, color, alpha and canvas coordinates (x, y or x0, y0, x1, y1, thickness; the variables W and H give its size):

    type Own fields
    text text with {expression} or {expression:%.2f}, scale, align (left, center, right), spacing, halo, outline, shadow
    rect, outline, line, gradient (color_bottom) Shapes
    corners (length), bar (fill, background), image (texture) Viewfinders, bars, images
    marker at (world position), size, length, margin, text, scale, edge_arrow

    Geometry

    Elements with type (billboard, beam, ring, disc, sphere, cylinder), render (additive, additive_texture, translucent), texture, at, to, color, color_end, alpha, size, rotation, width, radius, inner, segments, normal, when.

    14. Expressions

    numbers 1, 2.5, 1e3 · constants pi, tau, e, true, false
+ - * / % ^ (power) · < <= > >= == != · && || ! · c ? a : b
    Functions
    Math sin cos tan asin acos atan atan2 sqrt abs sign floor ceil round fract min max clamp sat mix lerp step smoothstep pow exp log log2 log10 mod hypot remap progress between if
    Envelopes window(t, in0, in1, out0, out1), swindow (soft edges), decay(x, k) or decay(t, start, k), impulse(x, attack, release), spring(x, frequency, damping)
    Easing smooth smoother ease_in ease_out ease_in_out ease_out_back ease_out_elastic ease_out_bounce
    Rhythm pulse(t, start, end, f0, f1[, shape]) (phase of a pulse that speeds up without jumps), beat(phase, sharpness), wave(s, hz), saw, tri, square(x[, duty])
    Seeded random noise(x[, channel]), fbm(x[, octaves]), rand(i), randr(i, min, max), hash(i[, seed])
    Physics arrival(distance): ticks the sound takes to arrive

    Variables: t (continuous ticks; whole numbers in actions), tick, s (seconds), age, duration, speed, seed (0–1), partial, ox oy oz (origin), cx cy cz (camera), dist, stopping, stop_t, local, the parameters (vectors also as name_x/_y/_z/_w and name_0…; colors as name_r/_g/_b/_a), state, vars, W and H in the HUD and event_<key> in events. An unknown variable is NaN and you get a warning once.
