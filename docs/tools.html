    Settings and tools

    Accessibility options, commands, the recommended workflow and how to keep the cost low.

    15. Settings and accessibility

    config/blocmpact.json (created at startup):

    Option Default Effect
    postProcessing true Turns off all of level 3 (effects keep their particles, sound, HUD and geometry)
    flashScale, shakeScale 1 Multiply flashes and shakes (0 removes them)
    impactFrames, heldFrames true Impact frames and held frames (abrupt full-screen changes)
    cinematics true Cutscenes that take over the camera
    particleDensity 1 Multiplies the particles that go through lod
    maxEffects 32 Simultaneous effects; the oldest is dropped
    gpuBudgetMs, pixelBudget 8, 2.3 GPU budget and millions of pixels for the passes
    warmupMsPerFrame 25 Shader precompilation when entering the world
    debugOverlay false Active effects and GPU time on screen

    Design every effect so it still reads without flashes or impact frames: many people will turn them off.

    16. Commands

    /blocmpact play <type> [pos] [params]          server, permission 2; params in SNBT: {radius:12, color:"#FF8800"}
/blocmpact play <type> on <entities> [params]  one per entity, following it
/blocmpact stop <id>|all [immediate]
/blocmpact event <id> <name> [params]
/blocmpact speed <id> <speed>                   0 pauses; any other value resumes or changes the speed
/blocmpact list

    Reserved keys in the command params: _seed, _speed, _range, _tracked (ticks, or -1 until stopped).

    /blocmpactc play <type> [params]       local, where you look
/blocmpactc play_on_me <type> [params] local, following you
/blocmpactc speed <type> <speed>       local, where you look, at that speed (0.05–8)
/blocmpactc stop | list | skip | debug

    17. Workflow

    1. Script first. One sentence, one reference, the shape that reads in half a second, two tones plus white, and a table of moments in ticks: anticipation, impact, resolution.
    2. Start at the lowest level that gets the idea across (particles and sound) and go up only when needed.
    3. Iterate live. With the effect in JSON or with shaders, F3+T reloads and /blocmpactc play replays it. /blocmpactc debug shows effects, resolution and GPU time.
    4. Validate shaders outside the game with glslang (download): python tools/validate_fx.py <glslang> <blocmpact-assets> <your-assets>. Try it first with a deliberate error.
    5. Look at it in the real game, ideally with a Fabric client gametest that takes screenshots before, during and after the impact (do it in a copy of the project with fabricApi { configureTests { enableClientGameTests = true } }; write preferredGraphicsBackend:"opengl" in build/run/clientGameTest/options.txt). Review the screenshots together and tune until nothing burns to white for more than 0.2 s.
    6. Try speed 0.5 (/blocmpactc speed): it must give the same film in slow motion.

    18. Performance

    • Beyond range() an effect costs nothing; tune it.
    • Passes run at a resolution that adapts to the measured GPU time (without stalling the GPU), and the compositor restores the scene's detail.
    • In shaders: exit early (if (r > 1.2) return …), compare with sceneT before computing anything expensive, bound your loops.
    • If you do not ask for bloom, the bloom chain does not run.
    • Persistent targets and history are released on their own once unused.
    • Particles: 20–50 per tick for continuous effects, up to 200 for bursts, always with lod.
    • Shaders are precompiled gradually when entering the world: no hitches in the middle of an effect.
