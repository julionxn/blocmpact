    Getting started

    An effect in JSON with no compiling, the same one in Java, and how to launch it, stop it and talk to it from the server or the client.

    4. Your first effect in JSON

    Create assets/mymod/blocmpact/effects/pulse.json in a resource pack or in your mod:

    {
  "duration": 60,
  "defaults": { "radius": 5, "color": "#FFFFFF" },
  "vars": { "k": "window(t, 0, 5, 40, 60)" },
  "timeline": [
    { "from": 0, "to": 40, "every": 4, "do": [
      { "particles": {
          "particle": { "type": "blocmpact:fx", "color": "$color", "size": 0.15, "size_end": 0, "lifetime": 15, "blend": "additive" },
          "shape": { "type": "ring", "radius": "radius", "phase": "t * 0.2" },
          "count": 24,
          "velocity": { "type": "fixed", "vector": [0, 0.05, 0] } } }
    ] }
  ],
  "geometry": [
    { "type": "ring", "at": [0, 0.05, 0], "radius": "radius", "inner": "radius - 0.3", "color": "color", "alpha": "k" }
  ],
  "screen": { "vignette": { "amount": "0.4 * k" } }
}

    Try it (F3+T reloads JSON and shaders):

    /blocmpactc play mymod:pulse {color:"#66CCFF", radius:8}      only you, no permissions needed
/blocmpact play mymod:pulse ~ ~ ~ {color:"#66CCFF"}            every nearby player

    The full format reference is in section 13.

    5. Your first effect in Java

    public final class SparkFx extends VisualEffect {
    public SparkFx(EffectSpawn spawn) { super(spawn); }

    @Override public int duration() { return 40; }

    @Override protected void onTick(TickContext ctx, int t) {
        if (t == 0) {
            int color = params().getColor("color", 0xFFFFFFFF);
            var spark = FxParticles.options().color(color).size(0.12f, 0f).lifetime(12).additive().build();
            ctx.particles().emit(spark, Shape.sphere(origin(), 0.3), 60, Velocity.along(0.15, 0.4));
            ctx.sounds().at(SoundEvents.AMETHYST_BLOCK_CHIME, origin(), 1f, 1.6f);
        }
    }

    @Override public void screen(Frame f, ScreenFx s) {
        float since = since(0, f.partial());               // seconds since tick 0
        s.flash(0.4f * (float) Math.exp(-20 * since), 1, 1, 1);
        s.shake(0.15f * (float) Math.exp(-12 * since));
    }
}

    Register it in your ClientModInitializer:

    ClientEffects.register(Identifier.fromNamespaceAndPath("mymod", "spark"), SparkFx::new);

    And launch it from the server (every nearby player will see it):

    Effects.spawn(serverLevel, Identifier.fromNamespaceAndPath("mymod", "spark"))
    .at(hit.getLocation())
    .color("color", 0xFFFFC040)
    .send();

    6. Launching, stopping and talking to effects

    From the server (Effects)

    FxHandle h = Effects.spawn(level, type)
    .at(pos)                      // or .on(entity) / .on(entity, Anchor.Point.EYES, offset)
    .seed(1234L)                  // optional: random by default
    .speed(0.5f)                  // slow motion on every client
    .param("radius", 12)          // numbers, booleans, strings, Vec3, vectors
    .color("color", 0xFFFF8800)
    .range(256)                   // players farther away do not receive it (512 by default)
    .to(players)                  // optional: only these players
    .tracked()                    // optional: late joiners see it too, entering at its current tick
    .server(new MyLogic())        // optional: server logic on the same clock
    .send();

h.event("hit", FxParams.builder().put("x", 1.0).build());     // reaches onEvent on every client and on the server
h.speed(0);                                                    // pauses every client and the server logic
h.speed(1);                                                    // resumes; any value changes the speed on the fly
h.stop();                                                      // ends with its outro (onStopRequested)
h.stop(true);                                                  // ends immediately

    An effect that is not tracked can be stopped and receive events for 10 minutes (lifetime(ticks) changes that). A speed change applies at the same point of the timeline on every client, and late joiners enter at the new speed. A paused effect cannot play its outro: stop() ends it on the spot.

    Server logic (ServerEffect)

    public final class RingDamage extends ServerEffect {
    @Override protected void onTick(int t) {
        double r = MyEffect.radiusAt(t, params().getDouble("radius", 10));   // the SAME function the shader uses
        if (t % 10 == 0) for (LivingEntity e : level().getEntitiesOfClass(LivingEntity.class, new AABB(origin(), origin()).inflate(r)))
            e.hurtServer(level(), level().damageSources().magic(), 4f);
    }
    @Override public boolean isDone() { return age() > 120; }
}

    If you register the logic per type with ServerEffects.register(type, params -> new RingDamage()), it also runs when the effect is launched by command. Put shared constants and curves in common code (src/main), and use FxMath for them.

    Client only (ClientEffects)

    ClientFxHandle h = ClientEffects.play(type, pos, FxParams.builder().put("radius", 4).build());
ClientEffects.play(EffectSpawn.local(type, Anchor.on(player), params).withSpeed(2f));
ClientEffects.play(EffectSpawn.local(type, pos, params), MyEffect::new);   // without registering the type

    Useful for interface effects, first-person item effects or previews. Only that player sees them. ClientFxHandle has stop, event, speed and effect() (the instance); its speed(v) only affects this client: for an effect launched by the server use FxHandle.speed, so the server and every player follow.

    Children and events

    From a tick, ctx.spawn(type, pos, params) launches another local effect with a derived seed: that is how bursts, aftershocks or debris are chained. onEvent(ctx, name, data) receives events from the server; onStopRequested(ctx) decides whether the effect ends right away (the default) or plays an ending and calls finish().
